# FronteraEval interface direction

The product is a research catalogue, not a poster, leaderboard, or benchmark marketplace.

## Principles

- Search is the primary action.
- Results lead to the original source, paper, and reference implementation before registry-host metadata.
- Evaluation origin, implementation provenance, and Inspect hosting are separate roles.
- Reviewed records state what the evidence supports and where the inference stops.
- Source-resolved metadata is not represented as independent methodological review.
- Typography is editorial but tool-sized; information density remains calm and legible.
- Agency Transfer is one curated collection inside a broader frontier-evaluation map.
